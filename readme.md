## 🌐 العربية

### 🕌 عن المشروع

**"الجامع المختصر لآراء المذاهب"** هو تطبيق ويب تفاعلي مفتوح المصدر يهدف إلى تسهيل الوصول إلى آراء المذاهب الفقهية الإسلامية (السنة، الشيعة، الإباضية) في المسائل اليومية، مع إمكانية مقارنة الآراء جنباً إلى جنب.

> ⚠️ **تنبيه**: هذا التطبيق **ليس موقع إفتاء**، بل منصة لعرض آراء الفقهاء للفهم والتبصر، مع توثيق المصادر.

---

### ✨ المميزات الرئيسية

| الميزة | الوصف |
| :--- | :--- |
| **مقارنة المذاهب** | اختر مذهباً واحداً أو أكثر لعرض آرائها جنباً إلى جنب. |
| **ثلاثة مستويات للإجابة** | مختصرة جداً (كلمة)، مبسطة (سطر)، مفصلة (عدة أسطر). |
| **بحث ذكي** | بحث نصي مع دعم البحث الدلالي باستخدام Gemini API (اختياري). |
| **نظام RAG** | ارفع نصوصاً مرجعية واحصل على إجابات مبنية عليها مع ذكر المصدر. |
| **استيراد CSV** | أضف آلاف المسائل دفعة واحدة عبر ملف CSV. |
| **مكتبة مصطلحات** | شرح مبسط للمصطلحات الفقهية الأساسية. |
| **موسوعة الأئمة** | تعريف بالأئمة المؤسسين وأشهر تلاميذهم. |
| **خريطة المذاهب** | عرض المذهب الرسمي السائد في كل دولة إسلامية. |
| **دعم 6 لغات** | العربية، الإنجليزية، الفرنسية، الفارسية، الملاوية، الأردوية. |
